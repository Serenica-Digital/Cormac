# Research Contract

This folder contains reusable topic knowledge. This is normally populated by the main claude / codex session working in the project, not necessarily the same PM agent writing our updates to adrs, the prd, etc. 

Organize files by technology, platform, domain, or integration. Do not organize them by session. 

## Rules

- Write for a future agent that needs to work with the topic.
- Include project-specific constraints and decisions.
- Link to primary sources when current external facts matter.
- Mark uncertain or time-sensitive claims.
- Update existing topic files instead of creating duplicate notes.
- Preserve lessons that prevent rediscovery: recurring traps, integration quirks, platform behavior, domain context, or subsystem patterns.
- Do not turn research notes into session logs. Omit abandoned attempts unless they explain why a future agent should avoid repeating a path.
- If a research lesson becomes a project constraint or settled fork, route it to PRD or ADR and link back only when useful.
