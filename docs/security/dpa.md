# Data Processing Agreement (DPA)

Status: stub (pending legal entity, ADR-001)
Maps to: subprocessors.md, data-retention-deletion.md, incident-response.md
Last reviewed: 2026-06-06

Blocked on: the legal entity (ADR-001). A DPA is a contract between two legal entities; it cannot be issued until ours exists.

## What it will contain

- Roles: the client is the data controller; Serenica Digital is the processor.
- Scope and purpose of processing.
- The subprocessor list ([subprocessors.md](subprocessors.md)) and the client's right to be informed of changes.
- Security measures (this packet is the technical annex).
- Data-subject request handling and deletion ([data-retention-deletion.md](data-retention-deletion.md)).
- Breach notification timelines ([incident-response.md](incident-response.md)).
- Data location and return/deletion on termination.

## To make this real

Resolve the entity (ADR-001), then adapt a standard processor DPA template with counsel, attaching this packet as the security annex. Confirm each subprocessor's own DPA is in place.
